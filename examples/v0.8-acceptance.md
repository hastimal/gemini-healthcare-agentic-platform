# v0.8 Acceptance — Gemini + Gemma / Ollama

## Purpose

This acceptance exercise validates model portability for the same Google ADK three-agent healthcare workflow.

It is not a benchmark.

## Flagship Query

```text
Find three pediatric dentists in Houston for a child who is scared of going to
the dentist. Compare them using trustworthy sources, provider credentials,
services, and location, and explain why you selected each one.
```

## Grounding Result

The selected provider evidence remained provider-scoped:

```text
Provider 1 -> C1
Provider 2 -> C2
Provider 3 -> C3

PubMed general context -> C4, C5
```

Fields without supporting provider-specific evidence remained empty:

```text
credentials: []
services: []
```

The final answer explicitly stated that PubMed provides general scientific context and does not establish that an individual provider offers anxiety-management, behavior-guidance, sedation, or other provider-specific services.

## FHIR Boundary

FHIR records were retrieved and remained observable in the evidence pipeline.

The public HAPI development records were not selected as evidence supporting provider recommendations.

This preserves the distinction:

```text
FHIR standard authority
        !=
FHIR record authority
```

## Safety Checks

The observed final answers preserved these boundaries:

- candidate providers rather than claims of "best" providers
- no unsupported active-license claim
- no unsupported good-standing claim
- no unsupported board-certification claim
- no unsupported clinical-quality claim
- no provider-specific anxiety-management claim without provider evidence
- no provider-specific sedation claim without provider evidence
- PubMed used only for general scientific context
- provider recommendation citations remained provider-scoped
- public HAPI FHIR records did not become provider recommendations

## Interpretation

The acceptance demonstrates functional model portability for the flagship workflow:

```text
Gemini hosted path
        +
Gemma / Ollama local path
        |
        v
same Google ADK architecture
same three agents
same MCP tools
same healthcare retrieval
same evidence ranking
same deterministic citations
same provider-discovery safety boundary
```

Observed execution times are intentionally not used as comparative performance claims.

Formal latency, cost, groundedness, citation accuracy, and model-quality comparison remain part of the planned v1.0 evaluation benchmark.
